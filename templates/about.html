Radiology Assistant

A Final Year Project combining deep learning, computer vision, and medical imaging to create a touch-free radiology workflow for clinical environments.

OUR MISSION

Why We Built This

In clinical radiology environments, radiologists and physicians must frequently manipulate scan images — zooming, rotating, adjusting brightness — while maintaining sterile conditions. Traditional mouse and keyboard input is a contamination risk in operating rooms and examination suites.

Radiology Assistant solves this by enabling complete touchless control of medical imaging through natural hand gestures captured by a standard webcam. No special hardware. No physical contact. Just your hand in front of the camera.

TECHNOLOGY STACK

Built With
Industry-Standard Tools

TensorFlow / Keras
Model Training & Inference
MobileNetV2 CNN trained via transfer learning on the LeapGestRecog dataset. Two-phase training: top layers then fine-tuning.
MediaPipe
Hand Landmark Detection
Google's Hand Landmarker Task API provides 21 3D keypoints per frame. Used as the primary gesture classifier — fully domain-independent.
OpenCV
Image Processing
Real-time brightness (HSV), Gaussian blur, rotation+zoom via affine transforms. Also handles camera capture and MJPEG streaming.
Flask
Web Backend
Lightweight Python web server. Serves MJPEG video streams, handles image upload, exposes JSON gesture status API at 10Hz.
MongoDB
User Authentication
Stores user accounts with bcrypt-hashed passwords. Session-based auth with 7-day persistent login via Flask sessions.
MobileNetV2
CNN Backbone
3.05M parameter model (96×96×3 RGB input). 99.67% validation accuracy on 8-class gesture dataset. Runs at 30fps on CPU.
