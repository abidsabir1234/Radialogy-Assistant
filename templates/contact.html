FAQ

Common
Questions

Do I need a special camera?
No. Any standard USB or built-in webcam works. MediaPipe's hand landmark detection runs on a regular 640×480 feed.
What image formats are supported?
JPEG, PNG, BMP, TIFF, WebP, GIF, JFIF, and JPE. Essentially any standard medical image format that isn't raw DICOM.
How accurate is gesture detection?
The landmark-based classifier is extremely reliable — it uses geometric finger distances rather than image patterns, so it works in any lighting and background.
Does it work on mobile?
The web UI is responsive, but gesture processing requires a webcam and runs server-side on Python/Flask — so a laptop or desktop is recommended.
Is patient data stored?
No patient data is stored. The uploaded scan is held in memory for the session and overwritten with each new upload. Only user account credentials are stored in MongoDB.
Can I retrain the model?
Yes. The training notebook (Google Colab) uses the LeapGestRecog dataset with MobileNetV2. You can adapt it to your own gesture set and replace gesture_v2.h5.
